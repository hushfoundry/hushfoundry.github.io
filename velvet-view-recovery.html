Velvet View Recovery

Encrypted cloud recovery for a personal media library managed on its owner’s computer.

What it protects

The backup component of The Velvet View saves a consistent copy of the local application database and configuration. This preserves personal decisions, clips, ratings, favorites, reviewed metadata, saved translations, and artwork evidence retained within the database.

Cloud recovery archives exclude media files, models, external image and thumbnail files, rebuildable provider catalogs, OAuth credentials, and the encryption key. Media and external artwork require separate file backups.

Why it connects to Google Drive

With the owner’s consent, the application stores encrypted snapshots in the selected Google Drive account. It downloads and decrypts each new snapshot to validate recovery before retiring older verified backups.

The application requests the limited drive.file permission for files created through its OAuth app or explicitly made available to it. It checks the connected account’s email address and available storage before writing. Its default schedule is 03:30 local time, with up to fourteen verified snapshots within a 2 GB retention budget.

Personal use

This website describes a personal Desktop application. The owner controls its computer, backup account, and separately saved recovery key.
