Privacy policy

J-Collection Recovery is a personal Desktop application operated on its owner's computer. Google access is used only to provide the encrypted backup and recovery features the owner enables.

Google data accessed and its purpose

The application uses the limited https://www.googleapis.com/auth/drive.file scope. It creates and manages its own encrypted backup files, repository marker, and verification receipts in the selected Drive account. It lists and downloads accessible recovery files for validation and restoration, and deletes older recovery files according to the retention policy only after a new copy has been verified.

The application checks the Google account's email address against the owner's selected backup account and checks available storage before a cloud upload. It does not request permission to read the account's entire Drive, Gmail, contacts, or calendar.

Storage and protection

Recovery archives contain a local catalog, personal collection decisions, reviewed artwork originals, and application configuration. Archives are encrypted on the owner's computer before storage in Google Drive; local recovery copies are also encrypted. Archived contents and filenames use rclone crypt encryption.

The owner retains the encryption key separately. Recovery archives exclude the key, OAuth credentials, collection video files, and generated thumbnail caches. OAuth tokens and client configuration are stored in the application's private local configuration with restricted filesystem permissions. Decrypted working copies used for verification or recovery remain on the owner's computer.

Sharing and use

The Desktop application sends encrypted recovery files to Google Drive and uses Google's OAuth service to obtain the owner's consent. HushFoundry does not operate a server that receives these backups, account details, or credentials.

Google user data is not sold, used for advertising, used to train AI models, or shared with unrelated third parties. Its use is limited to the backup and recovery functions described here. J-Collection Recovery's use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and owner controls

The default retention policy keeps fourteen verified recovery generations per destination. Backup failures can leave additional files so that previous successful recovery points are preserved.

The owner can disable scheduled backups, remove recovery files from local storage or Google Drive, and revoke the application's access through Google Account connections. Revoking access stops future authorized API access; it does not automatically delete existing backups or the local configuration.

This informational website

These static pages do not request Google access, use analytics, or embed tracking scripts. GitHub Pages hosts the site and may log visitors' IP addresses for security, as described in the GitHub Privacy Statement.

Contact and updates

The developer is HushFoundry. The application's Google consent screen provides its configured support email; the HushFoundry developer profile identifies its publisher. This policy will be updated if the application's handling of Google data changes.
