Privacy policy

Velvet View Recovery uses Google access only for the personal encrypted backup and recovery features enabled by its owner.

Google data and purpose

The application uses https://www.googleapis.com/auth/drive.file to create and manage its encrypted snapshots, repository marker, and verification receipts. It lists and downloads accessible backup files for validation and recovery, and removes older verified files according to the configured retention policy after a replacement verifies.

The connected Google account’s email address is checked against the selected backup account. Available Drive storage is checked before uploading. The application does not request access to the account’s entire Drive, Gmail, contacts, or calendar.

Storage and protection

Cloud archives contain the local application database and saved configuration. Contents and filenames are encrypted on the owner’s computer through rclone crypt before cloud storage. The owner keeps the encryption key separately; the key and OAuth credentials are excluded from recovery archives.

OAuth tokens and client configuration are kept in private local configuration with restricted filesystem permissions. Completed local archives and decrypted verification or recovery files are not encrypted by this cloud-backup feature and remain in private directories on the owner’s computer.

Sharing and use

The application sends encrypted backup files to Google Drive and uses Google OAuth for the owner’s consent. HushFoundry does not operate a server that receives these archives, account details, or credentials.

Google user data is not sold, used for advertising, used to train AI models, or shared with unrelated third parties. It is used only for the backup and recovery functions described here. Velvet View Recovery’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and owner controls

The default policy keeps up to fourteen verified cloud snapshots within a 2 GB retention budget. It preserves successful recovery points through failures; interrupted unverified uploads may remain for review. Local completed and failed-attempt archives are bounded separately.

The owner can disable scheduled backups, delete recovery files from local storage or Google Drive, and revoke future API access through Google Account connections. Revocation does not automatically delete existing files or local configuration.

This website

These static informational pages do not request Google access, use analytics, or embed tracking scripts. GitHub Pages hosts this site and may log visitors’ IP addresses for security. See the GitHub Privacy Statement.

Contact and updates

The developer is HushFoundry. The application’s Google consent screen supplies the configured support email. The developer profile identifies the publisher. This policy will be updated when Google data handling changes.
